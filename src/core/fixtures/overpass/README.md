# Overpass fixtures

Trimmed answers of the Overpass API (food places within 600 m of the Colosseum in Rome and of Dotonbori in Osaka), fetched
2026-11-07 for the tests of `food-find.ts`. Data © OpenStreetMap contributors, licensed ODbL 1.0
(https://www.openstreetmap.org/copyright). Phone numbers, e-mails and similar contact tags were removed. Used only as test input.
