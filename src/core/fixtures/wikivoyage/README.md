# Wikivoyage fixtures

The `Eat` section wikitext of three English Wikivoyage pages (Rome, Osaka, Tainan), fetched 2026-11-07 for the tests of
`wikivoyage-food.ts`. Text © Wikivoyage contributors, licensed CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/);
page history: https://en.wikivoyage.org/wiki/Rome?action=history (and Osaka, Tainan). Used only as parser test input, never
shown to users or stored in a trip.

`colosseo-eat.json` is the `{{eat}}` listings of the Rome/Colosseo district page reduced to name, alternative name, coordinates and
last-edit date (the descriptions, phone numbers and addresses were dropped); same licence and credit as above.
